# CodeOrbit Sales Data Analysis Task

This is my Task 2 submission for the CodeOrbit Tech Data Analyst internship.

## Project Title
Sales Data Analysis with Pandas - Sample Sales Dataset

## Technologies Used
- Python 3
- pandas

## Setup Instructions
1. Install pandas if you don't have it: `pip install pandas`
2. Run the script: `python3 analyze_sales.py`
3. It reads sales_data.csv and prints/saves all the summary numbers

## GitHub Repository Link
https://github.com/poojitha-sv/CodeOrbit_SalesAnalysis

## What This Project Does
I used a small sample sales dataset and analyzed it with Python and pandas - calculating total sales, average order value, top products, and breaking down sales by category, region, and month.

## Files Here
- sales_data.csv - the sample sales data
- analyze_sales.py - the script I used to analyze it
- Sales_Analysis_Report.md - summary of what I found
- sales_summary.csv, top_products.csv, sales_by_category.csv, sales_by_region.csv, sales_by_month.csv - the output tables from the script

## Quick Summary of Findings
- Total Sales: $1,647.24
- Average Order Value: $82.36
- Top product: Office Chair
- Top category: Furniture
- Weakest region: West

More details are in Sales_Analysis_Report.md.
